# MyPet

An App for pet owners register their pets and their medical information, to have control on their health history.

![cat](https://media.tenor.com/yaLiMF9X2psAAAAM/dragons-toothless.gif)

## Functional

### Use cases

User
- register
- login
- update profile
- update password
- update profile (name, email, city, role, licensing number)

Owner (user)
- add pet
- remove pet
- modify pet
- list pets
- add comment log for pet
- remove log
- modify log
- list logs for pet
- filter veterinaries
- assign veterinary
- unassign veterinary for pet

Veterinary (user)
- add action log for pet
- remove action log for pet
- modify action log for pet
- lists logs for pet
